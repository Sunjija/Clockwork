## 1. 기본 정보

- **제목:** 클락워크 (CLOCKWORK)
- **장르:** 2D 횡스크롤 픽셀아트 메트로베니아
- **플랫폼:** Steam (PC)
- **분량:** 본편 목표 약 10시간(ACT1·2·3) [확정], 졸업작품 범위 = ACT1(지하) 약 3시간 [제안]
- **팀:** 기획·스토리·연출 1인 + 유니티 개발 1인 (+ 아트 담당 합류 예정)
- **핵심 정서:** 시간이 멈춘 도시의 정적, 황금빛으로 굳은 사람들의 아름다움과 섬뜩함, 궁핍하지만 담담한 지하, 태엽과 기계의 따뜻함과 차가움의 공존
- **핵심 원칙:** 절차생성 없음, 영구사망 없음(맵은 손수 제작·영속). 무기·개조의 자유 조합으로 빌드 다양성을 준다.

## 2. 세계관·연표

**설정 핵심:**
- 환경 황폐화로 식물 성장 1/4로 둔화 → 기근 위기
- 크로노스 타워가 엘리아스가 발명한 인공 물질 '렌티움'을 합성·정제해 방출 → 실제로는 인간 인지 속도를 1/4로 늦춤(RUL-002). 정확한 원료·합성 원리는 정의하지 않음
- 타워는 렌티움을 두 경로로 공급: ①대기 방출(인간 인지 조절) ②폐쇄 배관망(기계 동력 공급, 20년 전 도입). 두 경로는 독립적으로 작동
- 지하 오수는 정제 렌티움이 아니라 '폐렌티움'(사용 후 불안정해진 찌꺼기). 정제 렌티움=기계에 안전한 연료, 폐렌티움=생물에게 위험·기계에게도 불안정, 밝은 황금색 시간 결정=말파스의 과출력으로 생긴 별도 보존 물질
- 폐렌티움은 배관망 회수 경로로 타워에 집결한 뒤 **타워 직하로 배출**된다. 지하의 오수 낙하 기둥(RGN-008)은 이 배출로의 지하 구간 — 타워 직하에서 교차로 대공동으로 쏟아지는 수직 기둥 + 대공동 저수 → 배수 수직갱 → 지하심층 저지대로 이어지는 유로 전체다(v5.5 B-1). 배출은 상시 있었으나 소량이었고 결정화 후 폭증해 현재의 폭포 규모가 됐다(E-2). 렌토가 정수장치 가동을 멈춘 동안에는 유입량을 처리하지 못해 통로와 저지대가 침수되며, 재가동 후에는 정수·배수 장치가 계속 들어오는 오수를 처리해 심층 수위를 반침수 운영선으로 낮춘다.
- **반전(진실):** 대중은 타워가 "시간을 가속한다"고 믿지만 실제로는 인지를 둔화시키는 것. 엘리아스와 말파스만 진실을 앎. 엘리아스가 은폐(RUL-003)
- 인간 인지 1/4 → 인간에게 외부 운동·낙하가 최대 4배 빠르게 체감(중력 자체는 불변, RUL-004). 티크 센서는 정상 물리값을 기록
- 인지속도 3단 구배: 중심(1/4) / 변두리(1/3~1/2) / 외곽(1, 정상). 시내/변두리 경계는 행정 구분, 인지 필드는 타워 중심 방사형 — 두 경계는 정확히 일치하지 않음 (E-7)
- **티크는 항상 표준속도** — 지상·변두리·지하 어디서든 인지, 이동, 전투, 입력, 애니메이션 속도가 렌티움 필드 때문에 변하지 않음. 지하 주민과 같은 정상 템포로 움직임
- **결정화:** 황금색 물질. 말파스가 의도적으로 일으킴. 도시 전역. 사람들은 죽지 않고 보존 상태. 부수효과로 렌티움 대량 방출 → 지하 오수 폭증 → 변이 생물(렌토 등) 출현(RUL-006, RUL-011)
- 지하 생물 변이 강도 = 오수 노출 깊이 + 농도/시점. 결정화 이전 점진 변이(하운드=식량 수준) vs 결정화 후 급성 강력 변이(렌토)
- 말파스는 딸을 잃은 후 전신 기계화(생물학적 영향 무관, 정제 렌티움은 동력으로 흡수 가능, RUL-007)
- ACT2 기계 몬스터의 변질 동기: 말파스가 클레아 연구에 출력을 집중하며 배관망 말단 정제도를 방치 → 기존 기계가 오작동·변질. 병기가 아니라 **"말파스가 버린 것들"**
- 안드레스(지하 도시) = 지하 20~25층. 지표 아래 B1~B19는 도시의 **기초 구조층(솔리드)**. 기초층 관통로는 셋뿐: ①폐기 슈트(하행 전용) ②오수 배출로(진입 불가) ③터미너스(유일한 등반로)

**연표:**
- 30년 전: 1차 분쟁(타워 건설 찬반). 반대파(모르비)가 지하로 망명. 엘리아스(40대)·말파스(20대, 제자)가 타워 설계
- 건설 표준 10년. 프로토타입 영향권 주민은 약 6년 8개월 체감·노화 → 완공 = 20년 전
- 완공 후 결정화 전 약 18년 6개월 동안 중심권 주민은 약 4년 7개월 체감·노화
- 2년 전: 2차 분쟁('시간 가속' 이견). 강경파(대표 비바츠) vs 온건파(엘리아스·말파스). 말파스의 딸 클레아(생물학적·사회적 16세)가 시계탑에서 추락→혼수
- 강경파가 탑 점거하나 가속 권한 없음(엘리아스만 보유, 변두리로 도피해 못 찾음)
- 점거 +6개월: 말파스가 습격 → 결정화 발동 → 도시 전역 정지
- 결정화 직후: 렌티움 대량 방출 → 오수 폭증 → 렌토 등 신종 변이 출현. 동시에 티크가 도움 청하러 타워에 올랐다가 말파스에게 내던져짐 → 파손 → 청소 로봇이 고철로 오인해 **시내 상업지구(시장 거리 하부)의 폐기 슈트**로 투하 → 슈트 종점 림부스에 폐기 → 비상 기능 정지. 기억 파편의 오수 유로 운반은 [제안 — E-8]
- 현재(결정화 후 약 1년 6개월): **티크가 림부스에서 재기동** → 다리에서 쥐떼 튜토리얼 → 파손 누적으로 다시 쓰러짐 → 모르비가 주워 칼리고서 수리 → ACT1 개시. 직접 재기동 계기는 미정

## 4. 칼리고 구역 정의

30년 전 시계탑 건설 반대파가 자발적으로 지하에 내려와 만든 마을. 떠밀린 게 아니라 선택한 것이라 궁핍해도 담담하게 살아감.

**생존 경제 3축:**
1. 폐기계 재활용 (림부스에서 주움)
2. 정화수 (렌티움 오수를 정수 장치로 걸러 식수 확보)
3. 변이 생물 사냥 (하운드=오수에 변형된 개 형태, 식량)

**현재 위협:** 렌토가 정수장치 내부에 둥지를 틀어 시설 가동이 정지 → 배수 중단·물이 끊김 (B-1: 몸으로 관을 막은 게 아니라 시설 정지) → 모르비가 티크에게 도움을 요청하는 동기.

## 5. 월드 구조 (3그룹 × 3지역)

**방위 (C-3, 지도가 정본):** 동측 = 시장 거리·폐기물 투입구·림부스(수거관 종점) / 서측 = 화물 터미널·터미너스, 변두리 끝 엘리아스 은신처 / 지하 서측 = 칼리고·정수장치.

**그룹 A · 지하 안드레스 (ACT1, 졸업작품 범위):**
지상 0F 기준 B20~B25.
- 지역1·시작권: 림부스-칼리고 다리(B20~21, 오수 폭포 횡단), 칼리고(B21), 림부스(B20)
- 지역2·중간권: 정수장치(B23), 교차로(B23), 정수장치 상부/갈고리 시험 공간(B23)
- 지역3·종착권: 지하심층(B25, 최하층 — 렌토 격파 전 출입 통로·저지대 침수, 격파 후 지속 배수되는 반침수 진흙 습지. **수영 조작 없음**, E-3), 터미너스(B22~23, 칼리고 서쪽에 붙은 수직 원통 갱도·ACT1 종착 출구, 상단은 서부 내벽 화물 승강장 → 화물 터미널)
- 오수 낙하 기둥(RGN-008): 지역이 아니라 수직 유로 — 타워 직하 → 대공동 저수 → 배수 수직갱 → 지하심층 저지대. 시설 정지 중에는 범람하고, 재가동 후에는 정수·배수가 유입량을 처리해 반침수 운영선을 유지한다(B-1).

**그룹 B · 지상 메티아 (ACT2, 설계 예정):**
시내(중심, 인지 1/4) / 변두리(엘리아스 위치, 인지 1/2) / 외곽(보호벽 바깥, 인지 정상·황폐). 화물 터미널 = CP·저장만 있는 전초기지, 제작·수리는 칼리고 유지 (E-6)

**그룹 C · 크로노스 타워 (ACT3, 설계 예정):**
하층부 / 중층부 / 최상층(옥상, 말파스 최종전)

## 6. ACT1 확정 동선

```
림부스(각성·첫 MOD 부품) → 다리(쥐떼 튜토리얼 → 쓰러짐) → 칼리고(모르비 수리·부품 판명)
→ 교차로 1차 통과(지하심층 문 목격 — 잠김·침수, 렌토가 정수장치를 정지시켜서)
→ 정수장치·렌토 격파 → 티크가 제어반 재가동(배수 재개) → 갈고리(ABL-002) 획득
→ 갈고리 시험 공간(RGN-015)에서 기억①(정체성) 회수
→ 교차로 2차 통과(수위 하강 → 문 열림)
→ 지하심층·지하 사냥꾼 격파 → 더블 점프(ABL-004) 획득 → 회수실에서 기억②(결정화 목격) 회수
→ 사냥꾼의 먹이굴을 역행 → 칼리고 봉쇄 사냥터 안쪽에서 귀환·마을 변화 확인
→ 칼리고 서쪽 화물문 → 고장 난 케이지로 터미너스 B23 하부역 진입
→ 터미너스·거대 거미(갈고리+더블 점프 둘 다 필요) → 지상 진출(ACT2)
```

**핵심 설계 원칙:** "가야 할 입구를 먼저 보여주고, 나중에 능력을 얻으면 자연스럽게 갈 수 있게" — 자물쇠를 열쇠보다 먼저 보여준다. (예: 교차로 대공동 1차 통과 시 지하심층 문GAT-101이 잠긴 채 목격되고, 렌토 격파·배수 재개 후에야 열림)

| 렌토 (Lento) | 중간보스/능력 보스 | 정수장치 | 결정화 후 오수 폭증이 낳은 거대 쥐. 정수장치 점거. 격파 시 갈고리 획득 |
| 지하 사냥꾼 | 보스 | 지하심층 | 곰충·갑각류 매복형. 심층에서 칼리고 얕은 사냥터까지 먹이굴을 파 식량 위기를 일으킴. 격파 시 더블 점프, 이후 회수실에서 기억② |
| 거미떼 | 잡몹(부하) | 터미너스 | 결정화 이전부터 건조한 폐쇄 화물축에 서식한 선주 생물(핵 없음, E-4) |
| 거대 거미 | 보스(ACT1 최종) | 터미너스 | 침수권에서 이동한 오염 생물을 포식한 한 성체에 폐렌티움이 생물 농축되어 급성 거대화(핵 보유, E-4). 터미너스 자체는 오수 유로가 아님. 갈고리+더블 점프 둘 다 필요. 기억 없음 |
| 말파스 | 최종보스급 | 크로노스 타워 옥상 | ACT3. 전신 기계화 |

**ACT별 보스-기억 원칙:**
- ACT1(지하, 생물): 보스는 순수 "길막이". 행동 패턴이 기억 내용과 무관하며, 기억 파편은 보스 진행 뒤 별도 공간에서 회수.
- ACT2(지상, 기계, 설계 예정): 기계 몬스터에 결합된 기억 코어 파편의 내용 자체가 패턴·기믹·디자인의 원천이 됨(예: "유대" 기억 → 들개형 몬스터가 하울링으로 개체 호출).

## 8. 기억 회수 시스템

**메커니즘 (3겹, 떠먹이지 않고 플레이어가 스스로 잇게):**
1. **섬광 컷신** (최소): 기억 파편 동기화 순간 1~2초 단편 이미지, 설명·대사 없음
2. **환경 서사** (주력): 컷신 파편을 다음 구간의 맵·오브젝트가 조용히 확증
3. **텍스트 로그** (양념): 티크의 건조한 기록, 짧고 사실만. 감정은 로그가 말하지 않음(건조함↔플레이어 감정의 간극이 게임 정서)

**기억① — 정체성** (렌토 격파 후, 갈고리 시험 공간에서 회수)
- 컷신: 공방에서 손이 어린 로봇 가슴을 닫아주는 장면(따뜻함) + 끝자락에 황금빛·높은 곳에서 내려다보는 시점이 0.3초 스침
- 환경: 칼리고의 투박한 지하 기술 ↔ 티크의 정교한 지상 제작 대비("나는 여기 출신이 아니다")
- 로그: `기억 파편 #1 동기화. 식별: 제작자 1인. 관계: 미정의.`

**기억② — 결정화 목격** (지하 사냥꾼 격파 후)
- 컷신: 화면 암전 → 도시 전체가 황금빛에 뒤덮이는 광경 0.5~1초
- 환경: 지하심층 진흙 속 정체불명의 황금 결정 파편들
- 로그: `성분 일치: 이전 기록 데이터와 동일 파장.`
- 기억①의 황금빛 위화감이 여기서 회수됨. 내려다보는 시점은 ACT2·3(말파스 연결)에서 회수 예정

**기억 파편 위치의 물리 근거 [제안 — E-8]:** 티크 파손 시 흩어진 조각이 오수 유로에 휩쓸려 운반됨 — 상부에 걸린 조각(기억①), 심층까지 침전된 조각(기억②). 회수 순서 = 낙하·침전 순서.

## 9. 게임 시스템 — 능력·무기·개조 삼원 체계

**이동 능력(ABL) = 영구, 보스 보상, 기억 복원과 별개 축**

| ID | 능력 | 해금 |
|---|---|---|
| ABL-002 | 갈고리 사출 | 렌토 격파 |
| ABL-004 | 더블 점프 | 지하 사냥꾼 격파 |
| ABL-003 | 벽타기 | 보류(설계 미정, ACT1 제외) |

**무기(WPN) — 로드아웃 시스템 (2026-07-20 확정)**
- 무기 풀은 본편에서 계속 확장한다. **장착은 동시 3슬롯 고정** — 어떤 3개를 담는가가 빌드를 정의.
- **맨주먹은 항상 사용 가능** (실질 공격 동사 = 주먹 + 장착 3종). 단, **주먹 강화는 로드아웃 슬롯 1개를 차지**한다 — "무기 2 + 강화 주먹" 같은 주먹 빌드 아키타입이 성립.
- 초기 3종: WPN-001 망치(느림·고데미지·묵직) / WPN-002 단검(빠름·저데미지·스타일리시) / WPN-003 대검(중간·중간·균형)
- 전투 중에는 장착된 무기 간 자유 교체(액션 계층). 로드아웃 구성 변경(전략 계층)은 **벤치에서만** (F-4 확정). 빈 슬롯이 있으면 새 무기 획득 시 그 자리에서 자동 장착.
- 공통 액션: 콤보 어택. (가드·패링은 보류 — v5.5 A-2, 방어 액션의 형태는 전투 시스템 회의에서 일괄 결정)
- 주먹 전환은 현재 장착한 외장 무기와의 조합만 사용 가능. ACT1 기본 로드아웃(망치·단검·대검)은 주먹 양방향 전환 6종을 제공.
- 유효 전환과 충분한 게이지가 있으면 스왑만으로 차지 전환 공격을 자동 발동하고 코어 충전을 소비. 부족하면 비용 없는 일반 스왑. 현재 10 에너지 비용은 제안 수치.

**콤보 매트릭스 — 핵심 6종 (주먹 축, ACT1 목표)**

| 전환 | 효과 |
|---|---|
| 주먹→망치 | 3연격 후 내려찍기, 스턴 |
| 망치→주먹 | 줄 감아 던지고 위치로 이동(유틸) |
| 주먹→단검 | 6연격, 출혈 부여 |
| 단검→주먹 | 단검 던지고 회수 시 대량 출혈 |
| 주먹→대검 | 빠른 3연격(대검 데미지) |
| 대검→주먹 | 내려베기 + 공격력 버프 |

**무기 간 6종은 본편 확장(ACT1 범위 밖, 보류):** 망치↔단검, 망치↔대검, 단검↔대검

**밸런스 원칙:** 특정 무기가 진행을 "불가능하게 막는 것"은 금지. "더 유리하게"는 권장.

**개조(MOD) = 무기 강화**
- **로드아웃 슬롯당 1개씩 귀속.** 3슬롯과 슬롯별 MOD 1개는 고정이며 `MOD 슬롯 +1` 성장은 사용하지 않음. 기본 주먹은 MOD 없음, 주먹 강화 패키지를 장착하면 해당 슬롯 MOD가 적용.
- ACT1 MOD: 림부스 첫 3택1 / 구 폐기물 선별장 고정 탐사 MOD / 정수장치-대공동 사이 폐쇄 송수로 유틸 MOD 3택1 / 사냥꾼이 미완 침전조를 파먹은 심층 굴착지 전투 MOD 3택1.
- 첫 보물방(림부스)은 **정체불명 부품**으로만 획득. 림부스는 오수 유로가 아니므로 결정 침전물이 아니라 오염된 고철·부품 더미로 표현.
- 정수장치 취수구는 렌티움 용량 파편, 터미너스 상단 정비 선반은 주요 보상 미정.
- 오염 구역(오수 기둥 등)은 생물 진입 불가 지대로 세계관·연출 요소로만 기능 (A-3 — 채집 콘텐츠 없음)
- 게임플레이: 표준 체크포인트 리스폰. 사망·리스폰의 세계관 설명은 미정이며 새 티크 제작 설정은 미채택.

**렌티움 코어 충전**
- 모든 유효 타격과 모든 적 처치로 공통 수급. 강적·보스의 약점 파괴·경직·처치는 등급별 추가 보너스 가능.
- 지상 기계와 지하 생물은 같은 전투 등급·성취 조건이면 같은 양을 제공. 지역·재질·렌티움 보유 여부에 따른 우대 없음.
- 확정 소비처는 홀드 회복과 차지 무기 전환. 구체 비용·회복 시간·중단 손실은 제안 수치.

## 10. 진행 중 — 아직 미확정 (다음에 이어서 정할 것)

- **회복·차지 전환 수치:** 전 지역 동일 수급·효율과 두 소비 구조는 확정. 남은 것은 비용, 홀드 시간, 중단 손실량, 강적 추가 보너스 수치
- **방어 액션:** 가드+패링 / 회피 중심 / 패링 단독 — 콤보 매트릭스와의 상호작용 포함해 전투 시스템 회의에서 일괄 결정 (A-2)
- **체크포인트:** 정체(벤치/충전소 등), 배치, 죽었을 때 정확히 뭘 잃는지 — 미정 (위치만 확정: 보스 직전 + 코너당 1개)
- **재화 시스템:** 잡몹 처치 보상, 범용 화폐 여부 — 미정
- **거대 거미·지하 사냥꾼 구체 패턴:** 컨셉만 있고 패턴 목록 없음
- **ACT1 시나리오 후반부 산문:** 교차로 2차~지상 진출까지 미작성 (렌토전·기억①까지만 작성됨)
- **ACT2·3 내부 설계:** 3지역 틀만 있고 구체 내용 없음
- **캐릭터 정본 문서:** 인물 카드가 임시 정본, 성격·말투 등 상세 자료 없음
- **미정·제안 총 24개:** 핵심 결정 13개 + 후순위·연출 제안 8개 + 제작 계획 3개. 전체 목록은 정본 12장 참조.

## 11. Unity 구현 현황 (2026-07-26 기준)

- 오프닝 슬라이스 플레이 가능: 림부스 각성 → 고철 언덕 점프 튜토리얼 → 정체불명 부품 획득 → 다리 고정 쥐떼 전투 → 치명적 기존 손상과 잔여 동력 고갈로 기능 정지 → 모르비 구조·칼리고 공방 수리 → 부품 판명 → 칼리고 광장 체크포인트 → 첫 통과 일방향 낙하 샤프트 착지. 수리 전에는 체력 2/5·이동 및 무기 출력 저하, 수리 후에는 체력 5/5·정상 성능으로 전환된다. 페이드 룸 전환, 피격 무적·넉백·리스폰, 무기 3슬롯(주먹/대검/망치 — 단검은 승인 아트 대기), 무기별 데미지 구현.
