# 티크 플레이그라운드

림부스 배경에서 티크의 이동·점프·더블점프·대시·공격을 직접 조작하는 독립 웹 프로토타입입니다. 선택한 revision 10의 원래 기본형 대기와 뒤쪽 팔 공격을 포함합니다. 설치할 프런트엔드 패키지는 없습니다.

## 실행

저장소 루트에서 Python 3으로 실행합니다.

```sh
python -m http.server 8780 --bind 127.0.0.1 --directory prototypes/tique-playground
```

브라우저에서 [http://127.0.0.1:8780/](http://127.0.0.1:8780/)를 엽니다. 이미 사용 중인 포트라면 다른 번호를 지정하세요. 애니메이션 메타데이터를 `fetch`로 읽으므로 파일을 더블클릭하는 대신 HTTP 서버로 실행해야 합니다.

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space / ↑ | 점프, 다시 누르면 더블점프 |
| Shift | 바라보는 방향으로 대시 |
| J | 뒤쪽 팔 공격 |
| Esc | 일시정지 / 계속 |
| R | 처음 위치로 |

좁은 화면에는 터치 버튼이 나타납니다. 창을 전환하면 자동으로 정지합니다.

## 현재 동작과 범위

- 발판을 벗어난 뒤 **120ms 코요테 타임** 동안 첫 점프를 허용하고 더블점프를 남깁니다.
- 착지 직전 **100ms 점프 입력 버퍼**를 적용합니다.
- 120Hz 고정 물리, 아래에서 통과 가능한 발판, 발판 밖 대시 후 낙하를 지원합니다.
- 선택한 스프라이트 비트맵을 그대로 표시하고, 걷기 프레임은 이동 거리에 맞춰 진행합니다.
- 공격 모션은 지상과 공중에서 확인할 수 있습니다. 적, 피해 판정, 스토리 진행은 구현 범위에 포함되지 않습니다.

## 구조

| 파일 / 폴더 | 역할 |
|---|---|
| `index.html` | 플레이 화면과 키 안내 |
| `Scene/play-controller.js` | 이동, 충돌, 코요테 타임, 점프 버퍼, 입력, 애니메이션 선택 |
| `Scene/play-scene.js` | 이미지 로드, Canvas 렌더링, 키·터치, 일시정지 |
| `Scene/*.png` | 기존 림부스 배경과 발판 타일 |
| `Revisions/10/` | 현재 프레임, 시트, APNG/GIF, Aseprite/Piskel 편집 파일 |
| `Revisions/04/`, `Source/` | 현재 메타데이터에서 직접 참조하는 제작 원본 |
| `asset-manifest.json` | 복사한 실행 코드·에셋·문서의 SHA-256 |
| `Tools/` | 컨트롤러 검사와 독립 패키지 검사 |
| `QA/` | 검사 결과와 기존 브라우저 확인 기록 |

## 검증

저장소 루트에서 실행합니다. 별도 라이브러리가 필요하지 않습니다.

```sh
node prototypes/tique-playground/Tools/play-check.cjs
python prototypes/tique-playground/Tools/check-package.py
```

컨트롤러의 11개 검사는 이동·경계, 코요테 타임 만료 전후, 점프 버퍼, 발판 밖 대시, 공중 공격과 중력, 키 반복, 30/60/144Hz 결과 일치를 포함합니다. 패키지 검사는 에셋 해시, PNG 프레임 크기, HTML·메타데이터의 파일 참조, 임시 로컬 HTTP 서버에서의 실제 파일 제공을 확인합니다.
