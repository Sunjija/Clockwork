# 문지기 V8 — 형태 뒤틀림 선택 보정

작업일: 2026-10-02. 사용자 요청은 보스 에셋 개선만이며, 마지막 게임
실행은 하지 않는다. 이번 작업에서 Unity 에디터·게임·플레이어 빌드·
런타임 캡처를 실행하지 않았다. 이전 실행 파일은 업데이트하지 않았다.
새 외형은 사용자 승인 전 후보이다.

## 수정 범위

대기 중 머리·몸통·관절이 프레임마다 변형되던 부분을 고정 자세와 미세한
환기구 색 변화로 정리했다. 턱 공격의 쐐기형 머리·눌린 주둥이·납작한
복귀 자세를 보정하고, 착지 폭을 183px에서 149px로 줄였다. 기존의 남청색
철판·회색 모서리·붉은 내부·측면 시점은 유지한다.

실제 이미지 생성 5개 수정 원본을 먼저 만들고 보여 준 뒤 검사했다.
기존 V7 32색·192×176 캔버스로 전체 자세만 균일 변환하고, 티크/문지기의
기존 PNG·Piskel·APNG·픽셀 델타 제작/내보내기 과정을 재사용했다.
다리나 머리를 별도로 늘이는 변형은 하지 않았다.

최종 변경은 `idle/00..07`, `wave-strike/00..02`, `slam-land/00,02`의
13프레임이다. 나머지 58프레임은 V7 PNG와 바이트까지 동일하다.
15클립·71프레임·클립 이름·재생 시간·노출 코어/피격 코어·의도된 구르기와
공중 회전은 유지했다. 티크와 퍼즐/가독성 에셋은 변경하지 않았다.

지지점 중앙값은 기존 163행 기준 그대로다. 턱 03/04의 최하단 한 픽셀은
164행이며 이 사실을 별도로 기록했다. 픽셀을 억지로 잘라 기준을 위장하지
않는다. 렌더러의 스케일, 전투 판정, 약점 위치, 애니메이션 선택 규칙은
변경하지 않았다. 게임 소스는 V8 리소스를 우선 읽고, 없으면 V7을 읽는다.

## 검증과 승인 구분

원본부터 네이티브까지의 독립 재구성 검사, 내보내기 APNG/Piskel/델타
재생, 팔레트·알파·Unity import 설정 검사와 순수 C# 프레임 선택
105,600건 검사를 진행했다. C# 모델 검사는 게임을 켜는 것이 아니며
이전 QA 기록을 덮어쓰지 않는 별도 폴더에 저장했다.

이 검사는 실제 실행 화면/연속 동작의 최종 승인이나 사용자 재미 검증을
대신하지 않는다. 이후 사용자가 실행을 요청하면 게임 빌드 및 실제 재생
확인을 별도로 진행한다.
