## 실제 창에 보낸 키

Sky로 반환된 WindowsV5 창에 키를 보냈다. 정상 제목에서 시작한 퍼즐은 시작 Enter→2.18초 새 Enter 스킵→동일 시작 칸/이동0→Left 이동1 → Z 되돌림0 → R 초기화0 → H 입력을 기록했다. Esc 정지 중 Right를 눌렀을 때 moves0과 같은 clock값을 유지하고 Esc 해제로 풀렸다.

전투 키는 `--return-input-check` QA 시작점에서 안전 안내를 열었다. 포커스 이탈로 정지된 상태를 먼저 풀고 새 Enter로 Combat에 진입했다. C는 dash=true, E는 charged=0, X는 attack=true; Z/Space/UpArrow는 각각 jumps=1/y<282; Left/Right는 실제 x 변화; Esc는 paused=true를 기록했다. 첫 안내 상태에서 전투키가 무시되는 기록도 남겼으며 성공한 전투키 기록과 혼동하지 않는다.

원본 기록은 `QA/WorkOrderV01/Manual/final-puzzle-input.jsonl`, `final-combat-input.jsonl`, `input-check-result.json`이다. 이 검사는 사람이 직접 게임을 완주한 검사가 아니다. Sky의 네이티브 창 캡처는 두 번 타임아웃되어 입력 결과는 접근성 창 확인과 게임의 Input.GetKeyDown/상태 기록으로 검증했다. 최종 빌드에서는 실제 키 입력마다 게임 렌더 화면도 저장해 20장의 실제 입력 캡처를 함께 확인했다. `key-final-*.png`가 해당 증거다. 이는 자동 공략135장과 별도로 보존한다.

## 미검증

사용자 최종 모션 품질 승인, 처음 보는 사람의 재미/난이도/소리 없는 의미 판독, 실제 손 입력으로 연속 더블점프·코요테 타이밍, 다른 고DPI 모니터는 미검증이다. 모델의 더블점프·코요테/버퍼 검사는 통과했지만 물리 키 검사와 구분한다. 상하 밀기의 2.5D 자세 자연스러움은 캡처를 참고해 사용자 플레이에서 확인한다.
