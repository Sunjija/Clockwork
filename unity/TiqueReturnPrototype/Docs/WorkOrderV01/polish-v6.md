## 제작 방식

- 문지기: `tools/art/author_iron_maw_rig.py`. 부위마다 정수 배치 + RotSprite(Scale2x 3회→최근접 회전→중앙 샘플) 1회, 기준 도트 32색으로 다시 맞춤, 닿는 발판은 바닥 132px에 평평하게, 늘어나는 다리는 새로 그린 피스톤 막대로 연결. 결과 60장(기존 5동작 52장 + 기동 4 + 정지 4), `art/return-v6-rig`.
- HUD·효과·아이콘·티크 자세: `tools/art/author_return_polish.py`. 문자 격자와 정수 픽셀 규칙으로 직접 찍으며 생성 이미지를 다시 샘플링하지 않는다. v5 경로를 그대로 덮어쓰므로, v5 `author_return_feedback.py`를 다시 실행했다면 이 도구를 그 뒤에 실행한다. 바꾼 클립 목록은 `art/return-v5-feedback/polish-v6.json`, 밀기 프레임의 팔 마스크는 `polish-v6-arm-masks.json`.
- 모든 새 PNG는 0/255 알파, 캔버스 크기·클립 이름·기준점은 v5와 같다.

## 검증 범위

이 작업은 Unity가 없는 클라우드 환경에서 했다.

- 통과: `Tools/ModelChecks`(기존 검사 + 작업 지시 37검사, 문지기 리그의 프레임 시간이 v0.3과 같은지 추가 검사), `Tools/Review-WorkOrder.py`(원본 309개 보존, 이진 알파, 글리프, 밀기 프레임의 머리·발이 팔 마스크 밖에서 Walk와 동일한지).
- 통과: 게임 스크립트를 Unity 2020.3 참조 어셈블리로 컴파일. Unity 6000.5 에디터 컴파일과 동일한 증명은 아니다.
- 미검증: 실제 Unity 임포트·Windows 빌드·실행 화면, 1배 화면에서의 효과 크기감과 타이밍, 사람의 모션·아트 승인. `Check-Source.ps1`, `Build-Windows.ps1`, 스모크 실행은 Unity가 설치된 PC에서 다시 돌려야 한다.
- `Review-WorkOrder.py`는 텍스트 원본 해시를 CRLF/LF 어느 쪽으로 받아도 비교하도록 고쳤다(`.gitattributes`가 LF로 받게 해 기존 해시와 어긋났다).
