# 문지기 v7 — 동작별 이미지 도트화와 게임 연결

2026-09-30. `art/generated/guardian-motion-images`(8개 동작 × 8프레임, 192×192)을 게임용 도트로 변환하고 전투 상태에 연결했다. v0.3 `WardenAuthored`와 v6 `WardenRig`는 비교용으로 남기고, 게임은 `Resources/ReturnV2/WardenV7`을 읽는다.

## 원본에서 확인한 문제와 처리

| 원본 상태 | 처리 |
|---|---|
| 도트풍이지만 한 장에 40색 이상, 노이즈 디더, 흐린 외곽선 | 면적 평균 축소 + 약한 샤픈(60%), 64장 공통 32색(몸 25색 + 입·노심·환기구 7색 분리), 저대비 단일 픽셀 흡수, 1px 외곽선 |
| 크기가 게임 기준(v0.3 몸 폭 136px)보다 큼(대기 폭 약 157px) | 전 동작 0.875배 |
| 낙하 내려찍기만 몸이 약 25% 작게 그려짐 | 그 동작만 1.33배 추가 보정 |
| 발판 높이가 프레임마다 1~5px 흔들림 | 발이 닿은 열들의 바닥 줄 중앙값을 기준선에 고정. 동작 안의 가로 움직임은 유지 |
| 대기 자세만 머리가 약 16px 높아 공격 시작·끝에서 머리가 한 번에 떨어짐 | 기존 프레임으로 이음: 돌진 전 피격 1번(입 닫고 반쯤 숙임), 충격파·낙하 전 경직 0번(입 벌린 중간 높이). 충격파 마지막(대기보다 낮게 한 번 더 숙임)은 빼고 6번에서 대기로 |
| 원본에 없는 연결: 구르다 기둥/벽에 부딪힘, 기동, 쓰러짐 순서 | 기둥 충돌 = 몸 펴기(돌진 5) → 경직 1·2 → 노심 노출(경직 3, 유지). 벽 충돌 = 몸 펴기 → 피격 2~7(머리 젖힘). 기동 = 쓰러짐을 거꾸로 재생하며 불빛 켜짐. 쓰러짐은 노심 노출 자세에서 이어지도록 2번부터 |

캔버스는 192×176, 발 기준선 163행(게임은 `bossY-164`에 그림). 가장 높은 자세(충격파 몸 세우기, 공중 회전)도 캔버스 안에 들어간다.

## 상태 ↔ 클립

| 게임 상태 | 클립 | 유지 프레임 |
|---|---|---|
| Rest | idle(8, 반복) | — |
| ChargeAim | charge-aim | 몸을 만 공 |
| Charge | charge-roll(3, 반복) | — |
| Open | stagger-open | 입 안 노심(판정 위치 = 몸 중심 앞 27px, 바닥 위 40px) |
| Recover(기둥 뒤) | stagger-close | — |
| Recover(벽) | charge-crash | — |
| WaveAim | wave-aim | 몸 세우기, 마지막 30ms 내려오기 |
| Wave | wave-strike(첫 프레임에 충격파 생성, 3단계 두 번째 충격파도 다시 내려찍기) | — |
| SlamAim | slam-rise(첫 130ms는 바닥에서 웅크림) | 공중에서 몸 말기 |
| Slam | slam-fall | 거꾸로 내리꽂기 |
| Recover(낙하 뒤) | slam-land | — |
| Down | defeat | 쓰러진 자세 |
| Arrival | boot(2.4초) | — |

`walk`는 현재 걷는 상태가 없어 예비로만 들어 있다. 노심 명중 때는 노출 자세의 노심 픽셀만 흰색→붉은색으로 번쩍이는 `core-flash`를 겹친다(예전 32×36 노심 스프라이트는 새 그림과 모양이 달라 그리지 않음).

## 게임 규칙에 준 변화

- 노심 판정 중심 `WeakX = bossX + facing*27`, `WeakY = bossY-40`(이전 48 / 20). 그림 속 노심에 명중 효과가 맞도록 옮겼다. 판정 폭(31px)·피해·타이밍은 그대로다.
- 그 밖의 수치(이동·예고·충돌 판정)는 바꾸지 않았다.

## 검증

- `Tools/ModelChecks`: 96,000회 상태·시간 조합에서 프레임 범위, 충격파 생성 프레임, 예고 유지, 낙하 130ms 접지, 노심 노출 유지, 벽 충돌, 쓰러짐 유지, 기동 2.4초를 검사한다. 자동 공략(장갑 파괴 3회 → 엔딩) 통과.
- 같은 검사가 전투 추적 기록 `QA/V7/fight-trace.json`을 남기고, 이것을 실제 프레임으로 합성한 미리보기가 `art/return-v7-guardian/QA/fight-preview.gif`, 주요 장면 `fight-keys.png`, 클립 전체 `clips.png`다.
- 게임 스크립트는 Unity 2020.3 참조 어셈블리로 컴파일 확인.
- 미검증: Unity 실제 실행 화면, 사람의 모션 승인. 낙하 착지 순간 몸이 넓게 퍼지는 프레임(폭 약 180px)이 피해 범위(±68px)보다 넓게 보일 수 있다.
