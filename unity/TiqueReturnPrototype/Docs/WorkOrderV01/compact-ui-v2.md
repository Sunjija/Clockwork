## 목표와 레퍼런스

큰 글씨와 상시 설명 카드가 게임보다 눈에 먼저 들어오는 문제를 줄인다.
평소에는 상태만 작게 보이고, 반복되는 실제 실패가 있을 때 짧은 전략을
자동으로 제공한다. 퍼즐 해답 경로나 정답 순서를 공개하지 않는다.

- [Dead Cells 공식 Breaking Barriers 안내](https://steamcommunity.com/games/588650/announcements/detail/3346752589077077088): HUD와 텍스트 표시 크기를 조절하는 방향을 참고했다. 외부 UI 아트는 복제하지 않았다.
- [Xbox XAG109: Objective clarity](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/109): 진행이 막혔을 때 선택 가능한 힌트·리마인더를 제공하는 방향을 참고했다. 아래의 구체적인 실패 횟수와 시간은 Clockwork 자체 튜닝값이다.
- UI/UX 점검 스킬의 키보드 선택 표시, 가려지지 않는 조작 요소, 안정적인 버튼 피드백을 검토했다. 웹/모바일의 SVG·터치 규격은 Unity 도트 게임에 그대로 이식하지 않았다. 화면 읽기 기능이나 완전한 접근성 준수를 주장하지 않는다.

## 평소 화면

- 기본 본문 14px / 보조 문구 12px / 큰 글씨 본문 16px. 640×360 논리 화면에서 정수 배율로 확대한다.
- 처음의 12px GPU 축소 후보는 한글 획과 R/숫자의 가독성이 떨어져 제외했다. 동일한 라이선스 폰트 원본을 실제 표시 크기로 직접 래스터화한다.
- 퍼즐: 왼쪽 위 회로 번호·이름, 오른쪽 위 추/구슬 소켓 진행도. 왼쪽 아래 작은 되돌리기·초기화 버튼. 상시 양쪽 설명 카드, 이동·밀기 통계와 H 힌트 버튼을 제거했다.
- 전투: 왼쪽 위 티크 체력, 위쪽 중앙 문지기 체력. 경고 때 패턴 이름만 표시한다. E 안내는 충전 기둥 근처에서만, X 안내·남은 노심 창은 노심이 열릴 때만 표시한다.
- 자동 안내: 퍼즐판 옆 또는 전투 바닥 아래에 짧게 표시하며 포커스/물리/타이머를 변경하지 않는다. 정상 플레이에서는 안내 패널이 없다.
- 일시정지: 계속하기, 소리, 효과 줄임, 자동 안내, 큰 글씨, 전투 재시작(해당 구간), 처음부터, 종료. 위·아래/Tab·Enter와 마우스로 선택한다. Esc로 복귀한다.
- 회색 연결 벽·손잡이 달린 황동 추·청록 구슬·사각/원형 소켓과 티크/문지기 아트는 기존 방향을 유지한다.

## 자동 안내 판정

| 상황 | 처음 안내가 나오는 기준 |
|---|---|
| 부품을 막힌 방향으로 밀기 | 서로 구분되는 실제 실패 3회 |
| 되돌리기 반복 | 실제 성공한 되돌리기 3회 |
| 방 초기화 반복 | 움직인 시도 뒤의 의미 있는 초기화 2회 |
| 구슬이 맞는 소켓을 통과 | 실제 통과 2회 |
| 부품을 이전 배치로 반복 이동 | 실제 밀기로 배치가 재방문되는 주기 3회 |
| 목표 진전 없이 계속 시도 | 활동이 있는 시간만 누적해 48초 |
| 같은 전투 패턴에 피격 | 실제 같은 원인의 피해 2회 |
| 닫힌 장갑 공격 | 실제 장갑 접촉 3회 |
| 노심 기회 놓침 | 실제 열린 창에서 공격하지 못한 경우 2회 |

표시 시간은 4.8초, 표시 시작 사이 최소 간격은 24초다. 다음 안내는 동일 문제의
전략을 조금 구체화한다. 일반 벽에 부딪힘, 방향키를 계속 누르는 자동 반복,
빈 초기화/되돌리기, AFK와 문구 읽기는 실패로 부풀리지 않는다.

전투 안내는 근거를 보관했다가 티크가 지상에 있고 공격/대시 중이 아니며,
피격 후 0.7초가 지난 Rest 또는 0.2초 이후 Recover에서 표시한다. 공격 패턴
도중에는 새 토스트를 띄우지 않는다. 성공과 구간 전환은 낡은 안내를 지운다.
죽은 뒤 재도전하면 유용한 패턴 지식만 유지하고 전투 상태는 원래 규칙대로
초기화된다. 설정에서 자동 안내를 끌 수 있다.

## 이미지-first 제작

새 패널/버튼은 실제 이미지 생성 2회 → 원본 표시·검토 → 네이티브 도트 변환
→ PNG/Piskel/APNG/픽셀 델타 → runtime export 과정을 거쳤다.
정확한 프롬프트, 참조, 생성 원본과 해시는 `art/return-ui-v2/Source`에 보존했다.
5개 skin은 생성한 동일 실루엣의 기본/선택/눌림/비활성 팔레트 상태다.
모서리를 고정하고 테두리는 원본 도트로 반복·끝부분 잘라내기, 중앙만 Point
확대한다. 새 임의의 프레임을 코드로 그리지 않는다.

폰트는 기존 SIL OFL NeoDunggeunmo 원본을 그대로 재사용한다. 승인된 16px
381개 glyph 타일은 RGBA-byte-exact로 유지하고 29개 누락 glyph를 같은 폰트로
보충했다. 12/14/20/24px atlas도 같은 원본 outline을 해당 크기로 표시한 것이다.
기존 화살표/조작 기호는 승인된 형태를 재사용하며 이전 Feedback 369개 파일을
변경하지 않았다. 이는 폰트 디자인 변경이나 AI 생성 글자 대체가 아니다.

실행 중인 이전 앱 바이너리에 이번 소스가 반영되었다고 주장하지 않는다.

## 재현

1. `tools/art/derive_export_ui_v2.py --export --inspected-native` — 검토된 원본·native 상태에서 아트 export/검증.
