# 티크: 귀환 — Unity 프로토타입 v0.1

**상태: Windows 빌드 성공. 실제 실행 파일의 1280×720 자동 플레이가 퍼즐부터 엔딩까지 통과했습니다.**

Unity 6 **6000.5.3f1**용 독립 프로젝트입니다. 기존 CLOCKWORK Unity 프로젝트와 웹 동작 실험실을 수정하지 않습니다.

2026-09-30 Unity Hub 로그인 후 Unity Personal 활성화를 확인했습니다. 실제 Unity 에셋 임포트, C# 컴파일, Windows 빌드, 실행 파일의 자동 플레이를 완료했습니다. 시작·퍼즐·문지기·엔딩의 한국어 화면을 캡처로 확인했습니다. 에디터 Play 모드, 사람의 키 입력 체감, 실제 청취, 1080p 화면과 5분 체험 분량은 별도 확인이 남아 있습니다.

## 구현한 체험 흐름

1. **시작:** 폐기 대상으로 분류된 티크가 귀환 경로를 찾습니다.
2. **폐기장 동력실:** 전력을 전자석으로 보내 추를 붙잡고 → 레일을 오른쪽으로 옮기고 → 문으로 전력을 돌려 추를 압력판에 내려놓습니다. 추의 무게와 문 전원이 모두 충족되면 문이 열립니다. 잘못된 조작 순서는 복구할 수 있습니다.
3. **공격 연습:** 문 앞 붉은 단자를 짧은 주먹으로 타격할 수 있습니다.
4. **출구 검사실:** 문지기가 위치를 추적·예고한 뒤 팔을 내리칩니다. 대시로 피하고, 내려온 붉은 손목 단자를 때립니다. 바닥 충격파는 점프로 넘습니다. 정비 자석으로 같은 표식의 팔을 붙잡으면 반격 시간이 늘어납니다.
5. **재검사와 엔딩:** 과부하 6칸을 해제한 뒤 오른쪽 단말에서 재검사합니다. 이름과 귀환처가 확인되면 출구를 지나 엔딩으로 갑니다.

사망 시 검사실에서 재시작하며 퍼즐 완료 상태를 유지합니다. 두 번 실패하면 공격 예고·반격 시간을 늘리는 도움을 선택할 수 있습니다. 짧은 한국어 스토리, 지연 힌트, 일시정지, 창 전환 시 자동 정지, 효과음·음소거를 포함합니다.

**5분은 최종 체험 목표입니다.** 현재 정답을 아는 입력 자동화는 약 48.3초에 완료했습니다. 이 값은 처음 플레이하는 사람의 소요 시간이 아닙니다. 실제 관람객의 퍼즐 이해 시간과 전투 실패 횟수를 측정하기 전에는 5분 분량이 완성됐다고 판단하지 않습니다.

## 실행하기

이 PC에서는 프로젝트의 **`Play.cmd`** 또는 **`Builds/Windows/TiqueReturn.exe`**를 실행합니다. Windows ZIP을 전달받았다면 전체 압축을 풀고 `TiqueReturn.exe`를 실행합니다. `.exe` 옆의 `TiqueReturn_Data`, `MonoBleedingEdge`, DLL 파일도 함께 있어야 합니다.

GitHub 저장소에는 소스와 검증 자료가 들어 있으며 빌드 산출물은 제외합니다. 소스에서 실행·빌드하려면:

1. 유효한 에디터 라이선스가 있는 Unity Hub에서 이 폴더를 프로젝트로 추가합니다.
2. **6000.5.3f1**로 엽니다. 추가 외부 패키지 없이 Unity 내장 모듈을 사용합니다.
3. `Assets/Scenes/TiqueReturn.unity`를 연 뒤 **Play**를 누릅니다. Game 뷰를 클릭하면 키 입력을 받습니다.
4. 씬을 찾기 어렵다면 상단 메뉴 **Tique Return → Open Prototype Scene**을 사용합니다.

Windows 빌드는 에디터를 닫은 뒤 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
./Tools/Build-Windows.ps1
```

Unity 경로가 다르면 `-Editor '설치 경로/Unity.exe'`를 지정합니다. 성공하면 `Builds/Windows/TiqueReturn.exe`가 생기며, 이후 `Play.cmd`로 실행합니다. 에디터 메뉴 **Tique Return → Build Windows Prototype**에서도 빌드할 수 있습니다.

`Tools/Open-Unity.ps1`로 에디터를 열 수도 있습니다. 에디터 실행·재빌드에는 유효한 라이선스가 필요하며, 빌드된 게임을 플레이할 때는 Unity Hub가 필요하지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → / A D | 이동 |
| Space / ↑ | 점프, 공중에서 더블점프 |
| Shift | 바라보는 방향으로 대시 |
| J | 선택했던 뒤쪽 팔의 짧은 공격 |
| E | 분배기·핸들·자석·검사 단말 조작 |
| Esc | 일시정지 / 계속 |
| M | 효과음 켜기 / 끄기 |
| F11 | 전체화면 전환 |
| Enter | 시작 / 사망 후 재시도 / 엔딩 후 처음으로 |

코요테 타임 **120ms**, 착지 전 점프 입력 버퍼 **100ms**, 공중 대시 1회, 피격 무적 **1초**를 적용했습니다. 대시 자체에 무적은 없습니다. 위험 범위에서 실제로 벗어나야 합니다.

## 아트와 애니메이션

- 승인된 revision 10의 64×64 티크 **67프레임을 바이트 그대로 복사**했습니다. Idle 1, Walk 14, Attack 12, Jump 15, DoubleJump 13, Dash 12입니다. 공중 동작은 상승·정점·하강·착지 상태에 맞는 프레임을 선택합니다.
- 머리·몸통·팔을 재조립하거나 늘리지 않습니다. 기본 대기 포즈, 발 기준선 y=56, 뒤쪽 팔 공격을 유지합니다.
- 전자석·추·문·문지기 몸체·주먹 등 **11개 소품을 정수 좌표와 16색 팔레트로 직접 작성**했습니다. 새 이미지 생성 서비스는 사용하지 않았습니다.
- 기존 Limbus 배경에서 640×360 배경 2종을 구성했습니다. 신규 소품은 프로토타입용이며 배경과의 질감 통일은 후속 아트 작업입니다.
- PPU 64, 10×5.625 카메라, 640×360 렌더 텍스처, Point 필터, 무압축, 밉맵 없음. 시뮬레이션은 소수점 좌표를 유지하고 화면에 그릴 때만 정수 픽셀에 정렬합니다.
- 효과음 8종은 짧은 합성 음원입니다. 한국어 UI는 Windows의 맑은 고딕을 사용하며 폰트를 별도 재배포하지 않습니다.

에셋 출처·해시는 `asset-provenance.json`에 기록했습니다. `QA/layout-study.png`와 `QA/assets-contact.png`는 **오프라인 합성 자료이며 Unity 실행 캡처가 아닙니다.**

`QA/validation-status.json`이 현재 검증 범위를 구분합니다. 직접 확인할 수 있는 검사:

```powershell
./Tools/Check-Source.ps1
python ./Tools/Review-Assets.py
```

첫 명령은 설치된 Unity에 포함된 .NET SDK와 관리 DLL로 일반 C#을 검사합니다. Unity 실행이나 플레이어 빌드를 대체하지 않습니다. 두 번째 명령은 선택적 아트 검토 도구로 Python + Pillow가 필요합니다.

`Tools/Build-Windows.ps1`로 빌드하고, 다음 명령으로 **같은 입력 자동화의 실제 Unity 실행 검사**를 수행할 수 있습니다. 일반 플레이에는 자동화가 켜지지 않습니다. 화면 캡처를 위해 게임 창을 표시한 상태로 실행해야 합니다.

```powershell
./Builds/Windows/TiqueReturn.exe --return-smoke --qa-dir ./QA/Runtime
```

실제 게임 캡처 7장과 통과 결과는 `QA/Runtime720Visible/`에 있습니다. `QA/layout-study.png`는 이전의 오프라인 배치 검토 자료이며 실제 실행 캡처와 구분합니다.

## 주요 파일

- `Assets/Scripts/ReturnModel.cs`: 퍼즐·이동·전투·진행 상태. Unity와 분리된 실제 게임 로직.
- `Assets/Scripts/ReturnGame.cs`: Unity 입력, 픽셀 렌더링, UI, 오디오, 실제 실행 자동 검증.
- `Assets/Scripts/ReturnPilot.cs`: 상태를 바꾸지 않고 일반 조작만 제공하는 검사 드라이버.
- `Assets/Scripts/ReturnChecks.cs`: 경계 조건과 실패 복구 검사.
- `Assets/Editor/ReturnBuild.cs`: 임포트 검사·씬 열기·Windows 빌드.
- `Assets/Editor/ReturnTextureImporter.cs`: 첫 임포트부터 픽셀 설정 강제.
- `Docs/implementation-log.md`: 구현 결정과 검증 과정.
- `Docs/design-v0.1.md`: 이번 프로토타입의 기획 기준 사본.

이 프로젝트는 졸업작품용 별도 각색 실험이며 원작 정사를 새로 확정하지 않습니다.
