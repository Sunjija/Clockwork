## 실제 화면 검토와 수정

720p에서 세 퍼즐의 조작 타일·소켓·티크, 야간 배경의 명암, 문지기의 돌진 예고선·충전 상태·장갑 노출을 확인했다. 구슬 안내문의 마지막 글자가 혼자 줄바꿈되어 문구를 짧게 나누었다. 수정 후 720p/1080p 자동 실행을 다시 수행했고, 1080p 퍼즐과 엔딩의 한국어 표시도 캡처로 확인했다.

최종 도트 접촉 시트에서 돌진 프레임 주변에 이웃 포즈의 턱 조각이 함께 잘리는 추출 오류를 찾았다. 사각 영역 전체를 복사하던 코드를 연결된 해당 캐릭터 픽셀만 복사하도록 바꿨다. 돌진 폭이 커질 때 다른 프레임까지 줄어들던 문제도 캔버스를 192px로 넓혀 해결했다. 결과는 `art/return-v2/qa/native-contact.png`에 남겼다.

## 남은 사용자 확인

- 실제 키보드 플레이의 이동·공격·회피 체감과 재미.
- 첫 플레이 기준 이해 시간·힌트 사용 횟수·보스 실패 위치.
- 새 문지기 실루엣·애니메이션·배경 밝기에 대한 사용자 승인.
- 실제 음향 청취, 에디터 Play 모드, 다른 운영체제와 게임패드.

현재 결과는 실행 가능한 개선 프로토타입이다. 전시용 최종 게임, 사람의 플레이테스트 완료, 목표 체험 시간 달성으로 표시하지 않는다.
